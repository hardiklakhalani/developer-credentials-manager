# Domain Glossary

## Core Concepts

### Credential Set
A preconfigured collection of credentials (email, password, subdomain, environment TLD, role) scoped to a specific backend server or environment, used to auto-populate authentication forms.

### Email List
A list of preconfigured email addresses available for selection via the in-field suggestion dropdown.

### Password List
A list of preconfigured passwords available for selection via the in-field suggestion dropdown.

### Dummy Data Set
A named collection of user-defined text entries (e.g., "Address", "Long Content") created to provide realistic mock data during testing and development. Sets start empty by default until created or populated by the user.

### Dummy Data Entry
A single piece of sample text contained within a Dummy Data Set. Can range from single-line strings (such as names or addresses) to multi-paragraph long-form text blocks.

### Random Dummy Data Filler
The browser context menu action available on editable fields that enables a user to select a Dummy Data Set; upon selection, a single Dummy Data Entry is chosen at random and injected into the target field.
